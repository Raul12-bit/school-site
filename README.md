# №2 Орта мектеп · ALATAU QALASY

## Выбранный стек

- **React + TypeScript + Vite** — быстрый, типизированный и удобный для поддерживаемого пользовательского интерфейса.
- **CSS design tokens** — общая цветовая система и полноценные светлая/тёмная темы без дублирования стилей.
- **Собственный i18n-модуль** — единые ключи интерфейса, сохранение языка и темы в браузере. На серверном этапе будет расширен переводами контента из БД.
- **Планируемые сервер и данные:** Fastify (TypeScript) API, PostgreSQL и Prisma ORM; S3-совместимое object storage для медиа. Это разделяет публичный клиент, защищённый API и файловое хранилище.
