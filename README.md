# №2 Орта мектеп · ALATAU QALASY

Первый этап — публичная главная страница школы. Основной язык интерфейса: казахский.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). Для production-проверки:

```bash
pnpm build
pnpm preview
```

## Выбранный стек

- **React + TypeScript + Vite** — быстрый, типизированный и удобный для поддерживаемого пользовательского интерфейса.
- **CSS design tokens** — общая цветовая система и полноценные светлая/тёмная темы без дублирования стилей.
- **Собственный i18n-модуль** — единые ключи интерфейса, сохранение языка и темы в браузере. На серверном этапе будет расширен переводами контента из БД.
- **Планируемые сервер и данные:** Fastify (TypeScript) API, PostgreSQL и Prisma ORM; S3-совместимое object storage для медиа. Это разделяет публичный клиент, защищённый API и файловое хранилище.

## Структура проекта

```text
public/                  # статические брендовые материалы
src/
  app/                   # корневой интерфейс и компоненты страниц
  i18n/                  # интерфейсные переводы и типы языков
  styles/                # глобальные токены, темы, адаптивные стили
docs/                    # архитектурные решения следующей фазы
```

После согласования этого этапа структура будет дополнена `apps/api`, `packages/shared` и Prisma-схемой. Клиент будет получать динамические данные только через API; в этом этапе примеры новостей и мероприятий служат исключительно компоновкой главной страницы, не имитацией готового API.

## Первый этап

- герб в шапке, hero-блоке/подвале и палитра на его основе;
- казахский интерфейс по умолчанию, переключение на русский и английский;
- переключатель светлой/тёмной тем с сохранением выбора;
- адаптивная навигация и мобильное меню;
- разделы главной: о школе, направления, новости, мероприятия, контакты и подвал;
- production-сборка проходит успешно.
